# 🎵 Song Downloader

Song name search ചെയ്ത് MP3 / MP4 download ചെയ്യാനുള്ള Streamlit app.

## Features
- 🔍 Song name / artist / movie name search
- 🎵 MP3 audio download (128 / 192 / 320 kbps)
- 🎬 MP4 video download (best quality)
- 📋 Top 8 search results with thumbnail preview

## Deploy on Streamlit Cloud

1. GitHub-ൽ ഈ repo fork/upload ചെയ്യൂ
2. [share.streamlit.io](https://share.streamlit.io) → New app → repo select ചെയ്യൂ
3. Main file: `app.py` → Deploy!

## Local Run

```bash
pip install streamlit yt-dlp
# ffmpeg install ചെയ്യൂ (MP3 conversion-ന്)
streamlit run app.py
```
